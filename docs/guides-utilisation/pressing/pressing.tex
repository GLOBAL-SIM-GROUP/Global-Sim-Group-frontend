% Introduction
\section{Avant de commencer}

Imagine que tu tiens une blanchisserie. Un client arrive avec un sac de vêtements sales. Tu écris dans un cahier : le nom du client, les vêtements qu'il a déposés, combien ça coûte, et quand il doit revenir les chercher. Quand les vêtements sont propres, tu changes une petite note dans ton cahier, et quand le client revient payer et repartir avec son linge, tu barres la ligne.

Le module \textbf{Pressing}, c'est exactement ce cahier, mais sur l'ordinateur. Une « commande », c'est le dépôt de vêtements d'un client. Pour chaque commande, l'application te permet de :

\begin{itemize}[label=\textcolor{lagoon}{\faFile}]
  \item \textbf{Noter le dépôt} : qui est le client, quels vêtements, combien ça coûte, quand il revient.
  \item \textbf{Suivre le travail} : la commande change de couleur au fur et à mesure (déposé, en traitement, prêt, retiré).
  \item \textbf{Encaisser l'argent} : le client paie quand il vient chercher son linge.
  \item \textbf{Imprimer un reçu} : un petit ticket à remettre au client.
\end{itemize}

\info{Chaque commande a un \textbf{statut}, comme un petit panneau de couleur : \textbf{Déposé} (bleu) → \textbf{En traitement} (orange) → \textbf{Prêt} (vert) → \textbf{Retiré} (gris). Une commande peut aussi être \textbf{Annulé} (rouge). Les demandes déposées par les résidents depuis leur portail arrivent en \textbf{En attente de validation} (violet) : elles deviennent de vraies commandes seulement après ton chiffrage — voir la section « Les demandes du portail résident ».}

\info{Deux façons de facturer : \textbf{à la pièce} (chaque vêtement a son prix — le mode habituel) ou \textbf{au kilo} (le linge est pesé, le prix se calcule avec le tarif au kilo en vigueur). Le choix se fait au dépôt et ne change plus ensuite — voir la section « La tarification au kilo ».}

\info{Ce que tu vois dépend de tes \textbf{permissions}. Si tu n'as pas le droit de créer ou de modifier, certains boutons n'apparaissent pas. Voir le récapitulatif à la fin du guide.}

% Section 1 : Ouvrir le module
\section{Ouvrir le module Pressing}\label{sec:ouvrir}

\begin{etapes}
  \item Connecte-toi à l'application.
  \item Sur l'accueil, clique sur la carte \textbf{Pressing}, puis sur « Commandes » ; ou clique sur « Blanchisserie » dans le menu latéral. Le menu propose trois entrées : \textbf{Commandes} (la liste ci-dessous), \textbf{Tarif au kilo} et \textbf{Catalogue} — les deux dernières sont réservées aux rôles autorisés.
\end{etapes}

\info{Une \textbf{pastille orange} avec un chiffre à côté de « Commandes » dans le menu signale les demandes du portail résident encore « En attente de validation » — elle disparaît quand tout est traité.}

La page \textbf{Commandes — Pressing} s'ouvre :

\screenshot{screenshots/pressing/01-commandes-liste.png}{La liste des commandes de pressing}

La page contient :

\begin{itemize}[label=\textcolor{lagoon}{\faList}]
  \item Un bouton \textbf{Nouvelle commande} en haut à droite : pour enregistrer un dépôt de vêtements.
  \item Une \textbf{barre de filtres} : pour retrouver une commande.
  \item Un \textbf{tableau} : une ligne par commande, avec son numéro, le client, les montants et le statut.
  \item Une \textbf{pagination} en bas : « Précédent » / « Suivant » quand il y a plus de 10 commandes.
\end{itemize}

\subsection{Lire le tableau des commandes}

Chaque ligne du tableau est une commande. Les colonnes sont :

\begin{itemize}[label=\textcolor{lagoon}{\faTable}]
  \item \textbf{N° COMMANDE} : le numéro unique de la commande (clique dessus pour ouvrir la fiche).
  \item \textbf{CLIENT} : le nom de la personne qui a déposé le linge.
  \item \textbf{DATE DÉPÔT} : quand les vêtements ont été apportés.
  \item \textbf{RETRAIT PRÉVU} : la date à laquelle le client doit revenir.
  \item \textbf{MONTANT} : le prix total de la commande.
  \item \textbf{ACOMPTE} : l'argent déjà versé. Le dépôt direct n'encaisse plus d'acompte (tout est payé au retrait) ; seule la validation d'une demande du portail peut en encaisser un — la colonne sert aussi pour les anciennes commandes.
  \item \textbf{RESTE} : ce qui reste à payer au retrait.
  \item \textbf{STATUT} : le petit panneau de couleur (Déposé, En traitement, Prêt, Retiré, Annulé).
  \item \textbf{ACTIONS} : les petites icônes pour voir, imprimer, modifier ou retirer la commande.
\end{itemize}

\astuce{Toute la ligne est cliquable : clique n'importe où sur une ligne pour ouvrir la fiche de la commande.}

% Section 2 : Filtrer
\section{Retrouver une commande}\label{sec:filtres}

La barre de filtres te permet de retrouver une commande quand la liste est longue.

\subsection{La barre de recherche}

Tape un numéro de commande, un nom de client ou un numéro de téléphone dans la case \textbf{Rechercher (n°, nom, téléphone)…}. La liste se met à jour automatiquement :

\screenshot{screenshots/pressing/03-filtre-recherche.png}{Recherche d'une commande par texte}

\subsection{Le filtre Statut}

Clique sur le menu \textbf{Statut} pour ne montrer qu'un seul type de commandes :

\screenshot{screenshots/pressing/02-filtre-statut-ouvert.png}{Le menu déroulant des statuts}

\begin{itemize}[label=\textcolor{lagoon}{\faFilter}]
  \item \textbf{Tous les statuts} : montre tout (c'est le choix par défaut).
  \item \textbf{En attente de validation} : les demandes déposées par les résidents sur leur portail, en attente de chiffrage.
  \item \textbf{Déposé} : les commandes qui viennent d'arriver, pas encore traitées.
  \item \textbf{En traitement} : le linge est en train d'être lavé ou repassé.
  \item \textbf{Prêt} : le linge est propre, le client peut venir.
  \item \textbf{Retiré} : le client est reparti avec son linge.
  \item \textbf{Annulé} : la commande a été annulée.
\end{itemize}

\subsection{Les autres filtres}

\begin{itemize}[label=\textcolor{lagoon}{\faFilter}]
  \item \textbf{Client} : tape une partie du nom pour ne voir que ses commandes.
  \item \textbf{Les deux cases de date} : la première est le « début », la deuxième la « fin ». Ensemble, elles montrent les commandes déposées entre ces deux dates.
\end{itemize}

\astuce{Tu peux combiner les filtres : par exemple « statut Prêt » + « client KOUASSI » pour voir uniquement les commandes prêtes de ce client.}

% Section 3 : Nouvelle commande
\section{Enregistrer un dépôt (nouvelle commande)}\label{sec:nouvelle}

Quand un client apporte son linge, tu crées une \textbf{nouvelle commande}.

\begin{etapes}
  \item Clique sur le bouton \textbf{Nouvelle commande} en haut à droite.
  \item Une fenêtre s'ouvre au milieu de l'écran.
\end{etapes}

\screenshot{screenshots/pressing/04-nouvelle-commande-vide.png}{La fenêtre « Nouvelle commande » vide}

\subsection{Choisir le client}

La première case sert à trouver le client :

\begin{etapes}
  \item Tape au moins \textbf{2 lettres} du nom du client dans la case \textbf{Client}.
  \item Une liste de clients correspondants apparaît en dessous.
  \item Clique sur le bon client : il s'affiche dans une petite puce.
\end{etapes}

\screenshot{screenshots/pressing/05-commande-client-choisi.png}{Un client sélectionné dans la fenêtre}

\info{Si le client n'existe pas encore, clique sur le bouton \textbf{Créer un client} en dessous : un mini-formulaire (nom, prénoms, téléphone, type de client) s'affiche. Remplis-le puis clique sur \textbf{Créer} : le nouveau client est choisi automatiquement.}

\subsection{Choisir la tarification}

Le choix \textbf{Tarification} décide comment le prix est calculé :

\begin{itemize}[label=\textcolor{lagoon}{\faBalanceScale}]
  \item \textbf{Tarification à la pièce} : chaque article a son propre tarif (le mode habituel, choisi par défaut).
  \item \textbf{Tarification au kilo} : le linge est pesé ; le prix se calcule avec le tarif au kilo en vigueur (voir « La tarification au kilo »).
\end{itemize}

\attention{Ce choix est \textbf{définitif} : une fois la commande enregistrée, on ne peut plus changer de mode — même en modifiant la commande.}

\subsection{Ajouter les articles}

Un « article », c'est un type de vêtement avec sa prestation (par exemple : 2 chemises à laver et repasser, ou 4,5 kg de draps à laver).

\begin{etapes}
  \item Pour chaque article, remplis \textbf{Type de vêtement} (ex : Chemise) et \textbf{Prestation} (ex : Lavage + Repassage). Ces deux champs sont des listes déroulantes alimentées par le \textbf{catalogue} — voir « Le catalogue ».
  \item Selon la tarification choisie : en mode \textbf{à la pièce}, ajoute la \textbf{Quantité} et le \textbf{Tarif} (prix d'une pièce, en FCFA) ; en mode \textbf{au kilo}, indique le \textbf{Poids (kg)} (ex : \texttt{4.500}) — la case Quantité disparaît, le poids fait office de quantité.
  \item Clique sur \textbf{Ajouter un article} s'il y a plusieurs sortes de vêtements.
  \item Clique sur \textbf{Retirer} sous un article pour le supprimer (il faut toujours garder au moins un article).
\end{etapes}

\screenshot{screenshots/pressing/23-select-catalogue.png}{Le « Type de vêtement » propose les entrées actives du catalogue}

Si le mot exact n'est pas dans la liste, clique sur le petit lien \textbf{Saisir manuellement} sous le champ : il devient une case de texte libre (le lien devient « Choisir dans le catalogue » pour revenir en arrière). Avec la permission \texttt{PRESSING.GERER\_CATALOGUE}, un second lien \textbf{Ajouter « … » au catalogue} apparaît : un clic et le libellé est enregistré dans le catalogue sans quitter la fenêtre — pratique pour un article qu'on reverra. Si le libellé existait mais était désactivé, le lien propose « Réactiver « … » » à la place.

\screenshot{screenshots/pressing/24-ajout-catalogue-inline.png}{Saisie manuelle + ajout direct au catalogue}

\info{En mode \textbf{au kilo}, une ligne « Aperçu » estime le montant de chaque article avec le tarif du moment (ex : « Aperçu : 7 200 FCFA (1 600 FCFA/kg) ») et le récapitulatif affiche « Total (aperçu) » : le vrai total est toujours calculé par le serveur. Si aucun tarif au kilo n'est configuré, un bandeau orange bloque la création — voir « La tarification au kilo ».}

\subsection{La date de retrait}

\begin{etapes}
  \item Choisis la \textbf{Date de retrait prévue} : le jour où le client doit revenir chercher son linge.
\end{etapes}

En bas, la ligne récapitulative calcule tout seul le \textbf{Total} :

\screenshot{screenshots/pressing/06-commande-remplie.png}{La fenêtre remplie : client, article et date}

\subsection{Enregistrer}

\begin{etapes}
  \item Vérifie que tout est bon.
  \item Clique sur \textbf{Enregistrer}.
  \item La fenêtre se ferme et la commande apparaît dans la liste avec le statut \textbf{Déposé}.
\end{etapes}

\screenshot{screenshots/pressing/07-commande-creee.png}{La commande créée dans la liste}

\attention{Les champs obligatoires : un client, au moins un article complet (type, prestation, et tarif + quantité à la pièce ou poids au kilo), et la date de retrait prévue. Si tu oublies quelque chose, un message rouge te dit quoi corriger.}

\astuce{Le dépôt n'enregistre aucun paiement : le client paie la totalité quand il vient chercher son linge (voir « Le retrait »).}

% Section 4 : La fiche commande
\section{La fiche d'une commande}\label{sec:fiche}

Clique sur une ligne du tableau pour ouvrir la \textbf{fiche} de la commande : c'est sa page détaillée.

\screenshot{screenshots/pressing/08-fiche-commande.png}{La fiche d'une commande}

La fiche montre :

\begin{itemize}[label=\textcolor{lagoon}{\faList}]
  \item \textbf{En haut} : le numéro de la commande, un badge « Tarification à la pièce » ou « Tarification au kilo », le nom du client, et les boutons d'action.
  \item \textbf{Le bloc d'informations} : client, téléphone, date de dépôt, retrait prévu, retrait réel, montant total, reste à payer, et le statut en couleur.
  \item \textbf{Le tableau Articles} : chaque vêtement avec sa quantité, sa prestation, puis son \textbf{tarif} (à la pièce) ou son \textbf{poids en kg} (au kilo — la colonne s'appelle alors « POIDS (KG) »), et son total.
\end{itemize}

\subsection{Faire avancer la commande}

Quand le travail sur le linge avance, tu changes le statut avec les boutons en haut :

\begin{etapes}
  \item Quand tu commences à laver le linge, clique sur \textbf{Passer en traitement}. Le statut devient orange « En traitement ».
\end{etapes}

\screenshot{screenshots/pressing/10-fiche-en-traitement.png}{La commande passée « En traitement »}

\begin{etapes}
  \setcounter{etapesi}{2}
  \item Quand le linge est propre et prêt à être récupéré, clique sur \textbf{Passer en « Prêt »}. Le statut devient vert.
\end{etapes}

\screenshot{screenshots/pressing/11-fiche-pret.png}{La commande passée « Prêt »}

\info{Les boutons changent selon le statut : « Passer en traitement » n'apparaît que si la commande est « Déposé », et « Passer en « Prêt » » que si elle est « En traitement ». Tu ne peux pas sauter d'étape.}

\subsection{Modifier une commande}

Si tu t'es trompé (mauvais article, mauvaise date de retrait), clique sur \textbf{Modifier} : la même fenêtre que « Nouvelle commande » s'ouvre, déjà remplie. Corrige puis clique sur \textbf{Enregistrer}.

\info{En modification, la tarification est affichée en lecture seule (« fixée à la création, non modifiable ») : tu peux corriger les articles et la date de retrait, jamais le mode.}

\attention{On ne peut plus modifier une commande « Retiré » ou « Annulé » : le bouton Modifier disparaît.}

\subsection{Imprimer le reçu de dépôt}

Le bouton \textbf{Reçu de dépôt} (icône ticket) sert à imprimer le petit papier qu'on remet au client quand il dépose son linge :

\begin{etapes}
  \item Clique sur le bouton \textbf{Reçu de dépôt} (sur la fiche, ou l'icône ticket dans le tableau).
  \item Un petit menu s'ouvre.
  \item Choisis \textbf{Ticket 58 mm} ou \textbf{Ticket 80 mm} selon la largeur de ton imprimante à tickets.
  \item Le ticket s'imprime ou s'ouvre dans une fenêtre d'impression.
\end{etapes}

\screenshot{screenshots/pressing/09-recu-depot-menu.png}{Le menu du reçu de dépôt}

\astuce{Le choix \textbf{Paramètres d'impression…} permet de régler l'imprimante une bonne fois pour toutes. Le reçu de dépôt est disponible dès le dépôt, même sans acompte — c'est différent du reçu de paiement (icône de téléchargement) qui n'apparaît que quand la commande est entièrement payée.}

% Section 5 : Le retrait
\section{Le retrait : encaisser le solde}\label{sec:retrait}

Quand le client revient chercher son linge, il paie ce qui reste. Le bouton \textbf{Retirer} sert à encaisser cet argent et à clore la commande.

\begin{etapes}
  \item Ouvre la fiche de la commande (ou utilise l'icône de la main avec une pièce dans le tableau).
  \item Clique sur \textbf{Retirer}.
  \item Une fenêtre s'ouvre : elle rappelle le numéro de commande et le reste à payer.
\end{etapes}

\screenshot{screenshots/pressing/12-retrait-dialog.png}{La fenêtre « Retrait — Pressing »}

\begin{etapes}
  \setcounter{etapesi}{4}
  \item Vérifie le \textbf{Montant du solde} (le reste à payer est proposé automatiquement).
  \item Choisis le \textbf{Moyen de paiement}.
  \item Clique sur \textbf{Valider le retrait}.
  \item La commande passe au statut \textbf{Retiré} (gris) : le client est reparti avec son linge.
\end{etapes}

\info{Le bouton \textbf{Retirer} n'apparaît que si trois conditions sont réunies : tu as les permissions \texttt{PRESSING.CREER} et \texttt{FINANCES.VOIR}, il reste de l'argent à payer, et la commande n'est pas déjà « Retiré » ou « Annulé ».}

\attention{Une fois la commande « Retiré », on ne peut plus la modifier. Vérifie le montant avant de valider.}

% Section 5a : Demandes du portail résident
\section{Les demandes du portail résident}\label{sec:demandes}

Les résidents peuvent déclarer un dépôt de linge depuis leur \textbf{portail résident}, sans passer à l'accueil. Ces demandes arrivent dans ta liste avec le statut \textbf{En attente de validation} (violet) : ce ne sont pas encore de vraies commandes — elles n'ont ni prix ni date de retrait, juste les articles déclarés par le résident.

\screenshot{screenshots/pressing/19-demandes-attente.png}{Une demande « En attente de validation » (badge violet) dans la liste}

Sur une ligne « En attente de validation », deux icônes spéciales apparaissent dans la colonne ACTIONS :

\begin{itemize}[label=\textcolor{lagoon}{\faList}]
  \item \textbf{Valider et chiffrer} (double coche, permission \texttt{PRESSING.CREER}) : ouvre la fenêtre de chiffrage.
  \item \textbf{Refuser la demande} (croix rouge, permission \texttt{PRESSING.ANNULER}) : annule la demande définitivement — elle passe au statut « Annulé ».
\end{itemize}

\subsection{Valider et chiffrer une demande}

\begin{etapes}
  \item Clique sur l'icône \textbf{Valider et chiffrer} de la demande.
  \item La fenêtre « Valider la demande de dépôt » s'ouvre. Elle rappelle le numéro de la demande : \textbf{vérifie les articles déclarés} par le résident et chiffre-les.
\end{etapes}

\screenshot{screenshots/pressing/20-valider-demande.png}{La fenêtre « Valider la demande de dépôt »}

\begin{etapes}
  \setcounter{etapesi}{3}
  \item Choisis la \textbf{Tarification} : à la pièce ou au kilo (les mêmes règles que pour un dépôt classique).
  \item Pour chaque article : type de vêtement, prestation, quantité et \textbf{tarif} (ou \textbf{poids} au kilo). Tu peux \textbf{Ajouter un article} ou en \textbf{Retirer} un si le résident s'est trompé — chaque ligne incomplète bloque la validation (« Indiquez le type de vêtement »).
  \item Indique la \textbf{Date de retrait prévue}.
  \item Si le résident a déjà payé une partie au comptoir, note-la dans \textbf{Acompte encaissé} (optionnel).
  \item Clique sur \textbf{Valider et chiffrer} : la demande devient une vraie commande au statut \textbf{Déposé}, avec son montant et sa date de retrait.
\end{etapes}

\screenshot{screenshots/pressing/21-demande-validee.png}{La demande chiffrée est devenue une commande « Déposé »}

\info{Après validation, la commande suit le cycle normal : En traitement → Prêt → Retiré. Le résident voit le prix et la date depuis son portail.}

\attention{Un refus est \textbf{définitif} : la demande passe à « Annulé » et ne peut pas être rouverte. En cas de doute sur les articles, contacte le résident avant de refuser.}

% Section 5b : Tarif au kilo
\section{La tarification au kilo}\label{sec:kilo}

Certaines commandes sont facturées au poids plutôt qu'à la pièce : draps, rideaux, grosses quantités de linge. Le prix se calcule alors avec le \textbf{tarif au kilo} en vigueur.

\subsection{La page « Tarif au kilo »}

Dans le menu \textbf{Blanchisserie}, clique sur \textbf{Tarif au kilo} :

\screenshot{screenshots/pressing/15-tarif-kg.png}{La page « Tarif au kilo — Pressing »}

La page montre le \textbf{tarif courant} (prix par kilo et date d'entrée en vigueur) et un formulaire pour en définir un nouveau :

\begin{etapes}
  \item Saisis le nouveau prix dans \textbf{Nouveau tarif (FCFA / kg)}.
  \item Clique sur \textbf{Définir le tarif} : le message « Nouveau tarif enregistré » confirme la prise en compte immédiate.
\end{etapes}

\attention{Définir un nouveau tarif ne change \textbf{jamais} le total des commandes déjà enregistrées : chaque commande au kilo garde le prix calculé avec le tarif en vigueur à sa création. L'historique est conservé — on ajoute un nouveau tarif, on ne modifie ni ne supprime l'ancien.}

\info{L'entrée « Tarif au kilo » du menu n'apparaît que pour les rôles ayant la permission \texttt{PRESSING.GERER\_TARIFS} (responsable pressing).}

\subsection{Créer une commande au kilo}

% Section 5c : Catalogue
\section{Le catalogue}\label{sec:catalogue}

Les listes déroulantes « Type de vêtement » et « Prestation » des fenêtres de dépôt ne sont pas fixes : elles se règlent dans la page \textbf{Catalogue} (menu \textbf{Blanchisserie} → \textbf{Catalogue}).

\screenshot{screenshots/pressing/18-catalogue.png}{La page « Catalogue — Pressing »}

La page a deux blocs identiques — \textbf{Types de vêtement} (chemise, costume…) et \textbf{Prestations} (repassage, nettoyage à sec…). Pour chaque bloc :

\begin{itemize}[label=\textcolor{lagoon}{\faList}]
  \item \textbf{Ajouter} : tape le nouveau libellé dans la case « Nouveau libellé » puis clique sur \textbf{Ajouter}.
  \item \textbf{Renommer} : l'icône crayon permet de corriger le libellé.
  \item \textbf{Désactiver / Réactiver} : l'interrupteur retire le libellé des saisies futures \textbf{sans toucher les commandes passées} — la ligne reste visible avec son badge « Actif » disparu.
\end{itemize}

\info{Tout le monde peut \textbf{voir} le catalogue (permission de lecture du pressing), mais seuls les rôles ayant \texttt{PRESSING.GERER\_CATALOGUE} peuvent ajouter, renommer ou désactiver : sans elle, les cases et boutons n'apparaissent pas. La même permission débloque aussi l'ajout express « Ajouter « … » au catalogue » directement dans la fenêtre de dépôt, sous les champs Type et Prestation.}

\section{Récapitulatif des permissions}

\begin{itemize}[label=\textcolor{lagoon}{\faKey}]
  \item Voir la liste et les fiches des commandes : permission de lecture du pressing (\texttt{PRESSING.VOIR}, donne aussi la lecture du catalogue).
  \item \texttt{PRESSING.CREER} : créer une commande (bouton « Nouvelle commande ») et \textbf{valider/chiffrer} les demandes du portail.
  \item \texttt{PRESSING.MODIFIER} : modifier une commande et changer son statut (« Passer en traitement », « Passer en « Prêt » »).
  \item \texttt{PRESSING.ANNULER} : refuser une demande « En attente de validation » (annulation définitive).
  \item \texttt{PRESSING.CREER} + \texttt{FINANCES.VOIR} : retirer une commande (encaisser le solde).
  \item \texttt{PRESSING.GERER\_TARIFS} : voir et définir le tarif au kilo (page « Tarif au kilo », réservée au responsable pressing).
  \item \texttt{PRESSING.GERER\_CATALOGUE} : ajouter, renommer ou désactiver les types de vêtement et prestations (page « Catalogue »).
  \item \texttt{PRESSING.DECLARER} : permission des comptes \textbf{clients/résidents} — déclarer un dépôt depuis le portail. Elle ne concerne pas le personnel.
\end{itemize}

\info{Les permissions se règlent dans le module Administration (page Rôles). Si un bouton manque, ce n'est pas un bug : c'est que ton rôle n'a pas le droit.}
